# Changelog

## 1.0.0

Initial open-source release of the OpenGander Web SDK.

- Page view and SPA navigation tracking
- Web Vitals (LCP, FID, CLS, TTFB, INP)
- User interaction and error capture
- Marketing attribution (UTM, referrer, traffic source)
- Built-in consent module with jurisdiction detection
- Token-based authentication (short-lived JWTs)
- Ghost inline variant for code injection
